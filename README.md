# 📱 Smartphone Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing smartphone specifications and pricing data using **MySQL**.

The analysis explores smartphone brands, pricing, ratings, screen sizes, battery capacity, camera specifications, RAM, 5G, NFC, IR blaster, refresh rate, and fast-charging features.

The main goal of this project is to use SQL to understand smartphone characteristics and identify patterns across different brands and features.

---

## 🎯 Project Objectives

The project answers different business and analytical questions such as:

- How many smartphones does each brand have?
- What is the average price of smartphones by brand?
- What is the maximum rating for each brand?
- What are the average screen size and battery capacity by brand?
- Does NFC availability relate to price and rating?
- How does extended memory availability relate to smartphone price?
- Which brands have the highest average prices?
- Which brand has the lowest average screen size?
- Which brands offer smartphones with both NFC and IR blaster?
- What are the most expensive smartphone models?
- Which brands have more than 20 smartphones in the dataset?
- Which brands have higher average RAM among phones with high refresh rates and fast charging?
- Which brands have 5G smartphones with sufficient records and higher average ratings?
